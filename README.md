# Reproducible Research Question & Analysis Preregistration

## Project Overview
This project studies whether daily study time is associated with students' examination scores.

## Research Question
Is there an association between students' daily study hours and their examination scores?

## Objectives
- Define the research question and hypotheses before examining real data.
- Document data inclusion and exclusion rules.
- Specify the statistical analysis plan.
- Maintain a reproducible project structure and Python environment.
- Test the analysis pipeline using synthetic data.

## Tools
- Python
- Pandas
- GitHub
- Automated unit testing

## Project Files
- `preregistration.md` — Research plan and hypotheses
- `requirements.txt` — Python dependencies
- `environment-lock.txt` — Environment record
- `pipeline.py` — Data validation and summary
- `test_pipeline.py` — Synthetic pipeline tests

## Testing
Run the tests using:

```bash
python -m unittest discover -s tests -v
```

## Expected Outcome
A documented research plan, reproducible repository, environment record, and passing synthetic pipeline tests.

**Note:** Synthetic data is used only for software testing, not as evidence for the research hypothesis.
